# Narration to Storyboard

Use only when the narration/script is finalized. The job is to design what the viewer must see while each spoken idea is heard, not to rewrite the narration.

## Step 1: Meaning ledger

For every sentence or semantic clause record internally:
- exact spoken text or stable clause ID;
- start/end timing if available;
- claim type: definition, example, contrast, process, question, qualification, conclusion, call-to-action;
- what the viewer must understand by the end of the clause;
- whether the meaning is concrete, relational or abstract.

## Step 2: Visual evidence

For each clause answer: “What visible change would prove this sentence has been understood?”

Prefer:
- definition -> establish a stable visual system, then show the defining transformation;
- contrast -> preserve common context while changing only the contrasted variable;
- example -> use a concrete scene whose visible cause/result maps tightly to the words;
- process -> show ordered cause -> transformation -> result;
- probability/distribution -> show population structure and relative recurrence, not decorative glow;
- agency -> show who chooses/acts and who remains a tool/background system;
- conclusion -> recombine established motifs rather than inventing a new metaphor at the end.

## Step 3: Find beat boundaries

Split when one of these changes:
- dominant claim or explanatory function;
- subject/observer;
- spatial layer;
- visual metaphor;
- before/after state;
- required camera objective;
- continuity strategy.

Do not split merely because a sentence ends. Do not preserve legacy segment counts.

## Step 4: Build generation units

Group adjacent beats when they share scene, continuity and a single model-executable transformation. Split when a unit becomes semantically overloaded, physically contradictory, or exceeds the target model's reliable duration.

Each unit must contain:
- narration range;
- one-sentence visual thesis;
- start state;
- 1–3 dominant visible events;
- end state;
- continuity/transition anchor;
- semantic acceptance criterion: what must be visible for the narration to be considered matched.

## Anti-filler rule

Never fill narration time with generic particles, slow pans, repeated blue glows, random characters looking at screens, or an unchanged map unless the stillness itself carries meaning. If there is no new visual evidence, redesign the beat.

## Output

Return a storyboard table with IDs derived from narrative order, not old production numbers. Include timing, narration clause, visual thesis, visible events, transition anchor and acceptance criterion. Prompt text comes later.
