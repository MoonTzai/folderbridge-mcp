# Shot Language Reference

Use camera language as an information tool.

| Narrative need | Useful visual strategy |
|---|---|
| Establish a system/world | wide/establishing frame, slow reveal, stable spatial anchors |
| Reveal hidden depth/source | push through foreground, rack/parallax, travel along a relation into depth |
| Compare same source under different viewpoint | preserve source geometry, rotate/orbit observer or camera, show changed projection |
| Compare different sources with similar output | parallel composition, matched framing on result, visibly different hidden structures |
| Show distribution/frequency | pull back to population-level topology; repeated routes/density differences must be spatially visible |
| Show trace-back/inference | follow an already-visible path from result toward source |
| Show re-projection | change coordinate/viewpoint while preserving underlying object/system |
| Show human choice | frame chooser and alternatives together, then show deliberate route selection/action |
| Show unknown/outside-map | preserve known boundary behind/aside while new space lacks established paths |
| Conclude | recombine established visual grammar; avoid introducing a brand-new metaphor |

## Motion rules

- Pan/track: reveal neighboring information within one stable space.
- Push-in: new detail or depth matters.
- Pull-back: context/distribution is the new information.
- Orbit/rotation: viewpoint/coordinate change is itself meaningful.
- Static shot: useful when state comparison or a deliberate pause matters.
- Hard/motivated cut: useful when changing example or conceptual layer.

Do not stack several movements merely to make a shot cinematic. One purposeful move is usually stronger.
