# Blender Toolkit — FolderBridge External Extension

Blender Toolkit is a global FolderBridge external Extension for Blender 5.x.

It has two cooperating pieces:

1. `blender-toolkit` — the FolderBridge Extension, installed under `%LOCALAPPDATA%\folderbridge-mcp\extensions\blender-toolkit`.
2. `folderbridge_blender_bridge` — a small Blender add-on installed into Blender's per-user add-on directory.

The Blender add-on exposes an authenticated loopback-only JSON bridge on `127.0.0.1:8766`. The FolderBridge Extension talks only to that fixed endpoint. A random 256-bit token is generated by `install.ps1`, copied to both sides, and covered by FolderBridge's exact-tree approval hash.

## Why this exists

`ComfyUI-Blender` solves **Blender → ComfyUI**.

Blender Toolkit solves **ChatGPT / FolderBridge → Blender**.

They are complementary and can be enabled at the same time.

## Capability model

The public surface is intentionally broad enough for production Blender scene authoring without exposing arbitrary Python, shell, command, executable, URL, or script execution.

The Extension supports:

- live Blender/bridge status and version reporting;
- direct verification of the `ComfyUI Blender` add-on and its `ComfyUI` N-panel registration;
- context, scene and datablock inspection;
- object/data/collection creation and deletion;
- exact transforms and general RNA property setting;
- exact mesh geometry replacement via vertices/edges/faces;
- modifiers and constraints;
- material/world/compositor/Geometry Nodes/node-group editing;
- node creation/removal/property/input editing/linking and node-group interface sockets;
- animation keyframe insert/delete and frame control;
- a broad **safe operator** surface for modeling, armatures, pose, transform, sculpt, paint, UV, animation, rigid bodies, view3d and node operations;
- workspace-confined `.blend` open/save;
- workspace-confined image load;
- workspace-confined OBJ/FBX/glTF/STL/PLY/USD/Alembic import/export;
- Blender screenshot return through MCP image content;
- still and animation rendering;
- headless Blender presence/version probe and fixed headless frame render.

### Deliberate security boundary

There is **no** `eval`, `exec`, arbitrary Python file, arbitrary shell, arbitrary command, arbitrary executable, arbitrary URL, or unrestricted `bpy.ops` action.

The generic operator action is restricted to a fixed family allowlist and rejects operator names or properties associated with file I/O, scripts, URLs, add-ons, extensions, install, console, quit, recovery, or factory-reset behavior.

File I/O actions accept only selected-workspace relative paths. Both the FolderBridge worker and Blender add-on independently resolve and enforce the workspace boundary.

This is intentionally "nearly all scene-production functionality", not "run arbitrary code inside Blender". Arbitrary Python would collapse FolderBridge's safety boundary and is therefore excluded.

## Install

From PowerShell:

```powershell
Set-Location C:\Claude\Project\folderbridge-mcp\Plugins\extensions\blender-toolkit
.\install.ps1
```

The installer:

1. copies the external Extension into `%LOCALAPPDATA%\folderbridge-mcp\extensions\blender-toolkit`;
2. generates/reuses the bridge token;
3. discovers the installed `blender.exe`;
4. asks Blender for its actual per-user add-on directory;
5. installs `folderbridge_blender_bridge`;
6. enables it automatically when Blender is not already running.

If Blender is already open, the installer does **not** mutate its live preferences from a second process. Restart Blender once and enable **FolderBridge Blender Bridge** in `Edit > Preferences > Add-ons` if necessary.

Then open FolderBridge **Extensions & Skills**, click **Rescan**, approve the exact new hash + declared permissions, and enable **Blender Toolkit**.

No FolderBridge rebuild and no MCP tool re-registration is required.

## Runtime

The Blender add-on adds a small `FolderBridge` tab to the 3D View N-panel. The `status` action reports:

- Blender version;
- current `.blend` path;
- bridge version/port;
- whether `comfyui_blender` is enabled;
- which known `ComfyUI` panel classes are registered;
- whether the ComfyUI N-panel is considered present.

For workspace-scoped actions, an unsaved Blender scene is allowed. If a `.blend` file is already open, it must live inside the selected FolderBridge workspace or the bridge rejects the operation with `BLENDER_WORKSPACE_MISMATCH`.

## Permissions

The external Extension declares only:

- `network.loopback:127.0.0.1:8766`
- `workspace.read`
- `workspace.write`
- `process.execute:blender.exe`

External Extension approval is a trust contract, not a kernel sandbox. The bridge executes inside Blender with the current Windows user's rights, so keep Blender files/assets within trusted workspaces.
